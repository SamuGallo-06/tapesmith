# Tapesmith
+
Tapesmith is a desktop application for managing physical cassette tape projects — from planning Side A/B track layouts, to dubbing digital audio files onto tape through a dedicated audio device, to digitizing existing cassettes back into digital form.

Built with PySide6, it provides a GUI, a CLI, and a pure-Python engine library that both interfaces share — so any workflow available in the app is also scriptable from the command line.

## Features

- 🎼 **Track planning** — lay out Side A/B tracklists with automatic duration tracking
- 🎚️ **Dub to tape** — guided wizard for recording digital audio onto physical cassettes
- 📼 **Digitize** — capture existing tapes into digital audio files *(in progress)*
- 🗂️ **Cassette library** — dashboard to manage all your cassette projects
- 🖥️ **CLI** — every core operation is scriptable, no GUI required
